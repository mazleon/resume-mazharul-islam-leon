# Mazharul Islam Leon — Resume

LaTeX source for the professional resume of **Mazharul Islam Leon**, Senior AI Engineer specializing in Computer Vision, Generative AI, and scalable ML systems.

## Quick Start

### Prerequisites

Install a LaTeX distribution (pick one):

- **macOS:** `brew install tectonic`
- **Linux / Windows:** Install [TeX Live](https://tug.org/texlive/) or [MiKTeX](https://miktex.org/)

### Build

```bash
# Using tectonic (recommended — automatic package resolution)
tectonic main.tex

# Or with traditional pdflatex
pdflatex main.tex
```

The output `main.pdf` is written to the project root.
